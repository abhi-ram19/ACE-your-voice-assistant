# ACE-your-voice-assistant
ACE is a Python-based intelligent voice assistant designed to recognize voice commands and perform real-time tasks through speech interaction. The assistant listens to user input, processes commands using speech recognition, and executes various automated actions.

🔹 Key Features:

🎙️ Voice command recognition using Google Speech API

🔊 Text-to-speech response using pyttsx3

🌐 Opens websites (Gmail, Instagram, ChatGPT, YouTube, etc.)

🎵 Plays songs directly from YouTube

⏰ Tells current time

📚 Fetches information from Wikipedia

🌦️ Provides live weather updates via API

📝 Saves voice notes to a local file

😂 Tells random jokes

💻 Opens system applications (Chrome, VS Code)

🔹 Tech Stack:

Python, SpeechRecognition, pyttsx3, pywhatkit, Wikipedia API, Requests API, NumPy, SoundDevice

🔹 Highlights:

Implemented real-time audio recording and processing

Integrated multiple APIs for dynamic task execution

Designed a continuous command loop system for uninterrupted interaction

Applied error handling for network and speech recognition failures

ACE demonstrates practical implementation of voice interfaces, API integration, automation, and real-time system interaction using Python.
